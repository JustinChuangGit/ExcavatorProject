# Import TestArea Into Unreal

This folder is generated by `python src/generate_world.py --config config.yaml`.

## Files Unreal needs

- `../metadata.json`
- `../terrain_heightmap.r16`
- `../instances/tree_instances.csv`
- `../instances/building_instances.csv`
- `import_generated_world.py`

## Recommended workflow

1. Put the whole generated world folder under your Unreal project:
   `Content/GeneratedWorlds/TestArea`
2. Enable the Unreal Python Editor Script Plugin if it is not already enabled.
3. Open Unreal Editor and run:
   `Content/GeneratedWorlds/TestArea/unreal/import_generated_world.py`
4. The script creates or opens `/Game/GeneratedWorlds/TestArea/TestArea`.
5. Landscape import from Python is engine-version-sensitive. If the script prints manual terrain instructions, import `terrain_heightmap.r16` as a Landscape using:
   - Width/Height: read from `metadata.json` field `heightmap_size`
   - XY scale: `metadata.unreal.xy_scale`
   - Z scale: `metadata.unreal.z_scale`
   - Format: 16-bit RAW/R16, little-endian, unsigned
6. Run the script again after the Landscape exists to spawn vegetation and buildings.

## Asset paths

At the top of `import_generated_world.py`, update `TREE_ASSETS` and `BUILDING_ASSETS` to point at project meshes. Missing assets fall back to `/Engine/BasicShapes`.

## Current prototype limits

- Trees use Hierarchical Instanced Static Mesh components grouped by `asset_type`.
- Buildings are placeholder boxes when no building mesh is configured.
- Roads and water are exported as masks/vectors but are not fully meshed yet.
- All CSV coordinates are local meters. The Unreal script converts them to centimeters.
